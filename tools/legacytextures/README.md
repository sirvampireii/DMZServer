# Legacy Textures

HD texture sets for DragonMineZ and NB Armors, with a per-player HD/vanilla switch (`/legacytextures` or the menu key).
Since 0.2.0 it also carries NB Armors itself (mod id `nbarmors`, package `nb/`); no separate nbarmors jar.
Since 0.2.3 it also carries the DragonMineZ face animation (blink and shout, package `faceanim/`, `/faceanim`);
no separate dmzfaceanim jar.
Full design, payload rules, the NB Armors findings and the deploy notes: [docs/LEGACYTEXTURES.md](../../docs/LEGACYTEXTURES.md).

| Path | What |
|---|---|
| `build.sh` | Clean build + every audit → `build/legacytextures-<version>.jar` |
| `src/main/java/com/dbzlegacy/legacytextures/` | `resolve/` set registry + resolver, `client/` hooks, menu, sets pack, DMZ cache flush, `server/` storage + command, `net/` packets, `mixin/` the four hooks, `nb/` the absorbed NB Armors mod, `faceanim/` the absorbed face animation |
| `src/main/resources/assets/legacytextures/*/hd/` | The HD payload (generated by `import/import_assets.py`; do not edit by hand) |
| `src/main/resources/legacytextures/texture_sets/` | The default set files copied to `config/legacytextures/texture_sets/` |
| `src/main/resources/assets/nbarmors/`, `data/`, `legacy_models/`, `nbarmors_*.json` | NB Armors resources, verbatim (`import/import_nbarmors.py`) |
| `src/main/resources/assets/dragonminez/textures/entity/races/*/faces/` | Face animation frames (`import/import_faceanim.py`) |
| `import/` | Payload import (`import_assets.py`, `IMPORT_MANIFEST.json`) and NB Armors resource copy (`import_nbarmors.py`, `NB_MANIFEST.json`) |
| `audit/` | Ship checks run by `build.sh` |
| `test/ResolverTest.java` | Resolver and registry rules (run by `build.sh`) |
| `test/clientprobe/` | Real-client smoke test (test-only probe mod + offline launcher) |

Regenerate the payload after a pack update:

```
python tools/legacytextures/import/import_assets.py --zone "<DMZ HD Plus.zip>" --nbhd "<Nb Armors HD.zip>" \
  --dmz <dragonminez-2.2.1.1.jar> --nb <nbarmors-0.1.0.jar>
```

Add `--check` to verify that the committed payload matches the zips without writing anything.
